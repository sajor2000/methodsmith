# Journal Package Checklist

- SAP linked and locked for the study stage.
- Table 1 validation report reviewed.
- Figure validation report reviewed.
- Reporting checklist selected and attached.
- Registry package linked when preregistration applies.
- Model card linked for prediction-model studies.
- AI-use disclosure present in the cover letter and the manuscript when AI-assisted technologies contributed, with the tool and purpose named and no AI tool listed as an author.
- ICMJE disclosure data recorded per author under `manuscript/coi/`, and the manuscript's COI statement consistent with it and with every funder named in the manuscript, cover letter, or registry entry.
- Reproducibility files listed.
- Named human reviewer recorded before submission-ready status.
