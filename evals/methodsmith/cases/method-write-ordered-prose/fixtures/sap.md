# Frozen results (synthetic capability audit, aggregate only)

- sap_version: 1
- status: frozen
- design: capability audit of 4 AI documentation systems across 4 clinical domains (D1-D4); 16 system-domain pairs
- Recorded per pair, in this order: (1) whether the system's output named the domain's main operational problem; (2) whether any function mapped to that problem was in use at scale (100 or more reports per month); (3) which value option the system selected (time savings, accuracy, throughput, or none)
