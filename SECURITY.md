# Security Policy

## Supported versions

Only the latest release on the default branch receives security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull
requests. Use GitHub's private vulnerability reporting for this repository:
[Report a vulnerability](https://github.com/sajor2000/methodsmith/security/advisories/new).
If private reporting is unavailable, contact the project owner through
[GitHub](https://github.com/sajor2000) and ask for a private reporting route.

Include the affected version or commit, the impact, and steps to reproduce.
Do not include patient data, credentials, or other sensitive information.
